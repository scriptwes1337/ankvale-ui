# Ankvale frontend system

Ankvale UI is a React frontend system by Ankvale Labs. Use its components, blocks, layouts, templates, animations, icons and graphics to build websites and applications with a consistent interface.

The system provides the presentation and interaction foundation so you can focus on your product's features and content. You can work directly with the code or use the included guidance to help a coding agent choose and compose the right pieces.

## What's included

| Layer | What you can use it for |
| --- | --- |
| Foundation | Shared colors, typography, spacing, appearance, density and motion preferences |
| Components | Forms, navigation, tables, dialogs and other reusable controls |
| Blocks | Complete page sections and application workflows |
| Layouts | App shells, sidebars, toolbars and responsive content regions |
| Templates | Starting screens for dashboards, mail, chat, CRM and finances |
| Motion | Consistent entrances, state transitions, presence and reordering |
| Icons and graphics | Phosphor icons and original product/hero compositions |
| Agent resources | Component catalogs, selection recipes, design guidance and coding skills |

## Design language

Ankvale's default appearance combines white and neutral surfaces, clear typography, generous spacing and blue primary actions. Light and dark appearances share the same structure. You can adapt the tokens and component styles to your own brand.

Icons and illustrations serve different purposes: use icons for compact actions and states, and larger compositions where a screen needs more visual explanation. The developing illustration family uses a neutral palette.

## How to build with it

Start with the template or block closest to your task. Adapt its content and layout, then use individual components for the remaining controls. Connect your application's data, authentication, permissions and services through the documented APIs.

The current web collection includes 176 component modules, 97 blocks including hero layouts, and five application templates. The icon browser includes 1,512 Phosphor icons in six weights. Explore the live previews to find the pieces that fit your application.

## Installation

Install the frontend system with `npx @ankvalelabs/ui init` in a Next.js App Router project. Manual React/Vite setup and the editable source registry are also available; see [Installation and first use](getting-started.md).
