# Component depth enhancements

This pass adds 13 reusable component modules and strengthens several existing components without changing their default APIs. No package dependencies were added. The preview map is `apps/web/components/enhancement-previews.tsx`; its static ID list is `apps/web/lib/enhancement-preview-names.json`. All new modules use Ankvale's existing neutral/blue tokens and existing primitives.

## Advanced boundaries still requiring product-specific work

- The grid does not provide spreadsheet fill handles/range replication, cross-row Excel-compatible functions, a chart-linked analytical panel or built-in PDF/Excel writer. CSV parsing/export and explicit callbacks are the supported transport contracts. Server sorting/filtering and import validation remain the data adapter's responsibility.
- A Tree movement callback does not mutate the caller's hierarchy automatically; the owner enforces valid parent/sibling moves. Tree cascade operates on known descendants and inherits selection when a selected parent loads a branch; ownership must enforce permissions for unknown descendants. Virtual Tree/Collection scroll measurements and keyboard focus restoration require browser review, and touch/assistive-technology certification remains outstanding.
- UploadManager composes with the separate ImageCropper through its transform hook; application code owns the crop dialog queue. Directory selection/traversal depends on browser `webkitdirectory` / entry API support, with flat-file fallback. There is no resumable/chunked provider protocol built into core.
- Scheduler recurrence is bounded to 366 daily/weekly occurrences, with IANA zones, gap/overlap policy and per-occurrence editing. It is not a general RFC 5545 engine. Its resource view uses the selected zone; the optional third-party week/month view uses the browser zone. Server conflict checks remain required. See [scheduling](scheduler.md).
- AdvancedChart supports validated acyclic multistage flows and geometric Cartesian navigation. Cyclic networks/crossing optimization, arbitrary date parsing and physical screen-reader or large-data certification remain outside this implementation. See [chart interactions](chart-interactions.md).
- Templates expose stable integration slots and data contracts; authentication, authorization, billing, email, AI services and backend persistence remain application integrations. Default demo datasets remain available rather than being represented as live business data.

These limits must remain visible in the backlog; file creation is not evidence of parity with every MUI X or Ant Pro feature.

## Verification

Run `node scripts/test-tooling.mjs tests/component-depth.test.tsx`. The focused suite covers all 13 preview SSR renders, password/clear focus, tag creation, stale async cancellation, localized numeric parsing, hex/RGB/HSL validation, row validation/save/undo/redo, safe formulas, CSV parsing/escaping, pivots, fractional ratings, tree rename/cascade/lazy inheritance, bounded 1,000-row virtual SSR, autosize fallback, upload concurrency, recurring exceptions/conflicts and external template adapters.

Package TypeScript checks pass with the current shared checkout. ESLint has no errors; only expected TanStack compiler-compatibility warnings remain in the new modules; the compiler deliberately skips those functions. Async grid loading derives from request identity and object-URL previews use commit-time ref cleanup without synchronous effect state writes. Registry generation, generated consumer examples and broad production build are coordinated by the parent agent so concurrent file generation does not race. Browser/device visual checks are separate from these automated checks.
