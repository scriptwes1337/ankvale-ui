## Native, website and tooling

React Native, React Native Web, `react-native-svg` and `libphonenumber-js` support the native components and previews. Next.js powers the website and documentation. The AI SDK and Model Context Protocol SDK support optional authoring and discovery tools.

We also thank the maintainers of TypeScript, Turborepo, ESLint, Babel, Prettier, esbuild, JSDOM, Testing Library, fflate and the other build and test dependencies listed in the package register.
