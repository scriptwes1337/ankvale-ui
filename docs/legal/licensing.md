## Required credit

Every app or website using Ankvale UI must display:

> Built with Ankvale UI by Ankvale Labs

Place this legibly in a footer, an About page, or a Credits or Legal screen accessible through normal navigation. A source-code comment or license file alone does not satisfy the visible-credit requirement. A logo or tracking integration is not required.

For example:

```tsx
export function Credits() {
  return <p>Built with Ankvale UI by Ankvale Labs</p>
}
```
